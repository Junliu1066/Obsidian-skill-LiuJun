# Index Update Rules

Update indexes only when the relationship is clear.

## Index update priority

1. Main learning index.
2. Domain-specific index.
3. Case/paper/project index.
4. Methodology index.
5. Expression/interview index when relevant.

## Entry format

```markdown
- [[目标笔记]]：一句话说明这个节点为什么属于这里。
```

## Safety

- Preserve existing index organization.
- Append under the most relevant heading.
- If no heading fits, add a small `待整理 / 新增节点` section.
- Do not reorder large indexes unless asked.
