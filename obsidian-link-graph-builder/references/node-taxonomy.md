# Obsidian Node Taxonomy

| Node type | Purpose | Common links |
|---|---|---|
| topic | Long-term learning area | cases, methods, projects |
| case | Product/company/project case | methods, competitors, expression cards |
| method | SOP, framework, checklist | cases proving it, projects using it |
| project | User's own project or work experience | methods, cases, bad cases, expression cards |
| paper | Research paper note | concepts, methods, project migration |
| skill | Agent executable workflow | SOPs, examples, templates |
| expression | Interview/speech/writing card | cases, projects, methods |
| concept | Reusable concept | methods, cases, papers |
| person | Thinker/founder/expert | ideas, writings, cases |

## Priority for index backlinks

1. Main learning index.
2. Relevant domain index.
3. Product/case/paper/project index.
4. Related method nodes.
5. Related project migration nodes.
6. Expression-card indexes if useful.
